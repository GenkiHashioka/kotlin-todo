## 学習目標

- `val` / `var` の使い分け
- null安全（`?`, `?:`, `!!`, `let`）
- `data class` と通常の `class` の違い

## 成果物

IntelliJ Kotlin Scratch File（`scratch.kts`）で、上記の各概念を実際に手を動かして確認した。

## 学んだこと

- `val`/`var`の使い分け（デフォルトは`val`、再代入が必要な場合のみ`var`）
- null安全: `?.`（安全呼び出し）、`?:`（エルビス演算子）、`let`（非nullブロック）、`!!`（非null断定、実行時例外リスクあり）を実装して確認。`!!`を外すとNPEが発生することも確認済み。
- `data class`の`copy`/`equals`/`toString`自動生成の挙動。**同一内容の別インスタンス（`person1Clone`）を用意し、equalsが参照ではなく値で判定されることを自ら検証**（想定した課題を超えた工夫）。
- 拡張関数（既存クラスを変更せずメソッドを生やす）: `Int.isEven()`
- `when`式（enumの網羅性チェックがコンパイル時に効くことを確認）
- 名前付き引数・デフォルト引数によるオーバーロード削減
- Kotlinクラスはデフォルト`final`、`open`を付けないと継承できないことを確認。さらに、**継承時に`class C : B()`のようにコンストラクタ呼び出しが必要な点に自ら気づいた**（Kotlinはプライマリコンストラクタでフィールド宣言と初期化が一体化しているため）

## レビューでの補足事項

- `person1.equals(person2)`という明示的な呼び出しは動作として正しいが、Kotlinの慣用的な書き方は`==`（構造的等価性、内部でequals()を呼ぶ）。参照比較をしたい場合は`===`を使う。Java出身者が引っかかりやすいポイントとして記録。
